📝 Guia de Mensagens de Commit — Git

📐 Estrutura Ideal

<tipo>: <assunto curto e claro>

[corpo explicando o porquê e detalhes, se necessário]

🏷️ Tipos de Commit

TipoQuando Usar
featNova funcionalidade
fixCorreção de bug
docsAlterações na documentação
styleFormatação, espaços, sem mudança de código
refactorReescrita/limpeza, sem mudar comportamento
perfMelhorias de desempenho
testAdição ou ajuste de testes
choreTarefas de build, configuração, dependências

✅ Exemplos Bons

feat: adicionar botão de compartilhamento
fix: corrigir erro de login com e-mail inválido
docs: atualizar instruções de instalação
refactor: reorganizar funções de validação
style: padronizar espaçamento nos arquivos JS
chore: atualizar versão da biblioteca axios

❌ Exemplos Ruins

ajuste
corrigir coisa
atualização
trabalho
wip

💡 Regras de Ouro

1. Comece com verbo no imperativo: adicionar, corrigir, remover, atualizar
2. Máximo de 50 caracteres na linha principal
3. Explique o porquê, não apenas o quê (o código já mostra o que foi feito)
4. Sem ponto final no título
5. Use letras minúsculas (consistência)
